# 🛠️ INSTALLATION

```bash
# Clone repository
git clone https://github.com/USERNAME/REPOSITORY.git

# Open project
cd REPOSITORY

# Install dependency
composer install

# Copy .env
cp .env.example .env

# Generate app key
php artisan key:generate

# Database migration
php artisan migrate

# Run localhost
php artisan serve
```
