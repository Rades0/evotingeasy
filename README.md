# 🌌 About Project

Cyberpunk-themed E-Voting application built using Laravel.

This application allows users to:
- Vote online
- Manage candidates
- View voting results
- Access admin dashboard

---

# ⚡ Features

```diff
+ Admin Dashboard
+ Participant Login
+ Online Voting
+ Candidate Management
+ Secure Authentication
+ Modern UI
```

# ⚙️ Installation

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```
